# Tofuya とうふや

Tofuya (Japanese for tofu store), is a command line application which focuses on the experience of switching between Terraform/Opentofu states in the same project.
This can be a great [time saver](https://en.wikipedia.org/wiki/Momo_(novel)) when your project has lots of states,
and it's annoying to constantly `tofu init` into them.
